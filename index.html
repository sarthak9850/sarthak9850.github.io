🧐 What is subcommit?

Imagine you’ve been working on several things at once in your project. With standard Git, you often have to remember complicated command lines just to commit only the specific files or even specific lines you want. This is called "partial staging" and it's notoriously tricky.

subcommit is a friendly, command-line tool that gives you the exact same power as that fancy "commit" window in your code editor (like VS Code or PyCharm), but right inside your terminal. It lets you choose which changes to include in your commit with a simple, interactive, and visual interface. No more memorizing git add -p or worrying about accidentally committing the wrong thing.

Think of it as a safety net: you see exactly what you're about to commit, select it, and commit with confidence.

✅ Key Features (No Jargon, Just Benefits)

  • 🎯 Select exactly what to commit: Choose whole files or specific lines within files. Say goodbye to unwanted changes sneaking into your commit.
  • 👀 See before you commit: Review your changes in a clear, readable format before finalizing.
  • 📦 Simple to install and use: No complex setup or needing to learn a new language. If you can run a command, you can use subcommit.
  • ⚡ Works everywhere Git works: Cross-platform, so it works on your Windows machine just as well as on a Mac or Linux computer.
  • 🔒 Safe and reversible: All your original work is preserved. If you make a mistake, you can easily start over. It's a wrapper around standard Git commands, so you're always in safe territory.
  • 🛠 Built for automation (Bonus for power users): It's designed with "agents" and "coding agents" in mind, meaning it's super fast and reliable on the command line.

🤔 Frequently Asked Questions

Q: Is this safe to use? I've never done this before.
Absolutely. subcommit works by using standard Git commands in the background. It doesn't do anything you couldn't do manually; it just makes it easier and safer. Your code's history remains completely intact.

Q: I don't know any "command line" stuff. Is this for me?
Yes! While you do type one command (subcommit), the program itself is a guided menu. It's very similar to going through a setup wizard—you just select options and they ask you to confirm before doing anything. You'll feel comfortable in under a minute.

Q: What if I get stuck?
The command-line will show you helpful prompts. If you ever feel lost, just press Ctrl+C to stop. You can also check the project's online documentation for detailed examples.
